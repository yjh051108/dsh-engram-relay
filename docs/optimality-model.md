# engram 记忆系统最优性建模报告（帕累托近似最优）

> 按数学建模竞赛规格：问题重述 → 假设 → 符号 → 模型 → 命题 → 校准 → 结论。
> 配套仿真：[fusion-simulation.md](./fusion-simulation.md)（三维度索引准确率）、
> `tests/simulate-fusion.mjs`、`scripts/fit-tau.mjs`（真实样本 τ 拟合）。

## 1. 问题重述

**目标（帕累托近似最优）**：唤醒注入的都是有用的记忆、存储的都是有用的记忆、
维护不复杂、自动与引导双轨都好、注入少而准。四项目标存在张力：
注入越少越省 token（成本）↔ 召回越全越好（收益）；存储越多覆盖越广 ↔
重复/过时节点污染候选集（噪声）。

**为什么严格帕累托最优不可计算**：价值函数依赖未来查询分布 Q（未知）。
退而求其次：对任意**给定的经验分布 Q̂**，模型可解；用离线仿真扫出
**经验帕累托前沿**，选膝点做工作点。

## 2. 符号

| 符号 | 含义 |
|---|---|
| M | 记忆库（N 条）；节点 i：向量 vᵢ、激活 Aᵢ、状态 sᵢ、入口成本 cᵢ |
| q ~ Q | 查询流（经验分布 Q̂ 由历史会话/wake-samples 校准） |
| π | 注入策略：候选集 C(q) 中选 I，\|I\|≤K，Σc≤B（预算） |
| u(i,q) | 效用（不可观测；代理：相关性标注/展开/强化） |
| c_store | 存储维护成本率 |
| G = (V,E) | 记忆图谱（因果边 + 双向链接） |

## 3. 模块模型与命题

### 3.1 注入（唤醒）：预算约束的 top-K

```
max Σ_{i∈I} u(i,q)   s.t.  |I| ≤ K,  Σ_{i∈I} c_i ≤ B
```

**命题 1（最优注入结构）**：入口成本 cᵢ 相同时，最优解 = 按 u 排序的 top-K
（贪心最优）。成本分级时 = 分数背包（按 u/c 贪心近似）。
**推论**：现有 wake.ts 的"排序 + 截断 + 预算"就是该最优解的贪心实例。
**已知缺口**：纯 top-K 在同主题簇内发散，损失多样性——补 MMR 式惩罚项
（战略篇原文"簇间多样性 MMR 式保证 3 条注入覆盖 3 个主题"）。

### 3.2 存储（写入）：边际价值固定点

**竞争效应**：库越大，单条记忆被选中的概率越低——

```
P(i ∈ I(q) | π)  =  E_q[ 1{rank(u(i,q)) ≤ K} ]
                 ≈  F_u(K/N)          （u 分布固定时随 N 递减）
```

**命题 2（存储的最优判据）**：存 i 当且仅当

```
E_q[ u(i,q) · P(i ∈ I(q)|π) ]  ≥  c_store
```

**推论（版本链必要性）**：重复主题的第 2..k 条记忆，其 u 与已有版本
高度相关但被"只注入当前版"规则排除 → P(被选) → 0 → 边际价值趋零而
存储成本 > 0 → **重复存储严格次优**。这从数学上证明：写前查重 + 版本链
（废止旧版）不是工程偏好，是竞争效应下的帕累托必要条件。
**实证**：真实 store 曾出现 7 组同名 16 条（P0 修复前）——竞争效应已发生。

### 3.3 遗忘（生命周期）：边际比较

价值 Vᵢ(t) 随强化历史衰减（已有幂律激活 Aᵢ = ln(Σ tₖ⁻ᵈ)），维护成本率
c_maint 恒定（索引/内存/候选集噪声）。

**命题 3（最优 dormant 化时刻）**：最优沉睡时刻 τ\* 满足

```
∂Vᵢ/∂t |_{t=τ*} = −c_maint
```

即"继续保留的边际收益 = 边际成本"时进入沉睡（dormant：退出注入入口层、
保留可检索、命中即复苏）。**推论**：c_store > 0 时"永不遗忘"严格次优——
遗忘（沉睡/废止）是帕累托前沿的组成部分，不是妥协。
**落地**：`dormantOf`（30 天无强化且 hits<3 的派生判定）+ 渲染降级。

### 3.4 结构（六度保证）：hub 簇有界路径

设每簇有代表节点 hub（簇概览，链接度最高者），记忆 i 连其簇 hub。

**命题 4（六度记忆）**：任意两记忆 i, j：

```
d(i,j) ≤ 2 + max(簇内径) ≤ 2 + O(1)
```

N 节点、C 簇时 |H| ~ √N（幂律网络经验），任意两记忆经 hub 可达，
**检索路径有界 ≤ 6 跳**（"6 个人串联世界"的记忆版本）。
**推论**：因果传播/渐进披露的深度上限可取 3-6（覆盖全图），
beam search 深度不需要大——给唤醒传播一个结构性复杂度边界。

### 3.5 PID 映射（动态归一化）

| 控制器 | 记忆系统对应 | 现状 |
|---|---|---|
| P（比例） | 当前相关性：语义 cos × 词汇精确 | ✅ wake 排序主项 |
| I（积分） | 历史强化积分：激活 Aᵢ = ln(Σ tₖ⁻ᵈ) | ✅ ActivationCache |
| D（微分） | 变化率：版本更新/主题趋势漂移 | ⏳ 未实现（P7+） |
| 增益调度 | τ_j 在线更新（按维度近期判别力） | ⏳ fit-tau.mjs 已可离线拟合 |

**命题 5（权重方向需数据驱动）**：三维度判别力随记忆库演化漂移——
融合仿真实测时序方向**反转**（recency AUC 0.304 = 旧更相关），
预设"越新越优先"严格次优。τ 必须按经验分布标定 + 在线更新
（样本 <200 不生效防过拟合，fit-tau 输出置信度）。

### 3.6 与 o1 的类比（最优记忆回溯）

| | o1 | engram |
|---|---|---|
| 搜索空间 | token 推理空间 | 记忆图谱 |
| 搜索 | beam search + reward | 唤醒 = 候选生成→排序→截断（beam 宽 K） |
| 预算 | 推理 token | 注入 token B |
| 扩展 | 深度推理 | 因果传播（深 ≤ 6，命题 4 有界） |

**命题 6**：唤醒 = 图上带预算 B 的 beam search；现有管线是宽 K、深 1 的
贪心实例；因果传播 = beam 扩展；簇 hub = 跳转。加上命题 4 的结构保证，
唤醒搜索**有界完备**（深度上限内可达全部相关簇）——这是 o1"最优记忆
回溯"在本系统的形式化对应物。

## 5. 结论

1. **帕累托近似最优可达**：对任意经验分布 Q̂，注入 top-K（§3.1）、存储
   边际判据（§3.2）、遗忘边际比较（§3.3）构成三个可解模块；四项目标
   的张力由竞争效应定量化。
2. **版本链/写前查重/沉睡/簇 hub 不是功能堆砌**，是竞争效应与有界路径
   的数学推论——每条机制都有对应命题。
3. **权重必须数据驱动**（命题 5）：已落地 fit-tau + 采样闭环，待样本
   积累后进入自动调参。
4. **边界声明**：严格帕累托最优不可计算（Q 未知）；本报告给出的是
   "给定经验分布下的最优 + 仿真验证的前沿工作点"。

## 6. 局限

- 效用 u 不可观测，全部用代理（相关性/强化）——代理偏差是最大不确定性源；
- 竞争效应 F_u(K/N) 的分布假设未用真实数据拟合（当前规模 N 小，效应弱）；
- 六度保证依赖幂律网络假设（真实图谱度数分布待测）；
- o1 类比是形式对应，不构成能力等价声明。
