# 统一大脑（Unified Brain）：自适应语义图 + 浅思维算子 + 灵枢校准器

> 大融合终版架构（A 方案：灵枢留作常驻校准器）。

## 架构总览

```
统一自适应语义图（agent 建边 · 强化遗忘 · 软簇）
 ├─ 存储层：节点=记忆/概念（agent 蒸馏+建边），边=agent 关联
 ├─ 召回层：词项激活 → 邻域 → 相关记忆（每轮自动）
 ├─ 浅思维：图上算子（条件/验证/边界）→ 3 行注入（每轮自动）
 └─ 深挖层：engram_open/recall/verify/respond（agent 主动·图上游走）

灵枢（常驻校准器）：
  · D_norm 验证闸门——图网络敢想，灵枢把关敢不敢说对
  · 诚实边界——不知道就说不知道（规范性判断，统计给不了）
```

## 信息流（单向，无冗余）

```
消息 → 词项激活（哈希）→ 邻域子图（1-2 跳）
  → 记忆入口（邻域节点，注入）
  → 浅思维三算子：
      条件  = 邻域 kind 分布（簇性质：知识/决策/情感/事件）
      验证  = 灵枢 auto_verify（D_norm 外部校准锚）
      边界  = 教训节点邻域边权 + 诚实边界词
  → 注入 3 行（记忆入口 + 浅思维）
  → agent 按需深挖（工具调用，图上游走）
  → 回合后蒸馏 + 建边（agent 自主）→ 图演化
```

## 分工（不可互相替代）

| 能力 | 归属 | 原因 |
|---|---|---|
| 存储/分类/召回 | 图网络 | agent 自组织，行为学权重 |
| 浅思维（条件/边界） | 图上算子 + 灵枢种子 | 统计给不了规范性 |
| 验证校准 | 灵枢 D_norm | 外部锚，防自嗨 |
| 深挖 | agent 工具（渐进披露） | 认知责任在 agent |

## 灵枢的最终角色

- 检索/分类/知识卡 → 已由图网络吸收（灵枢退出赛道）
- **D_norm 验证闸门** → 常驻校准器（每轮浅思维带验证行）
- **诚实边界** → 常驻（教训种子 + 边界词种子，随图演化）
- 翻译表/学科卡 → 种子记忆（一次性灌入图网络）

## 渐进落地

1. **浅思维注入**：knowledgeText（知识卡）→ thinkLight（条件/验证/边界 3 行）
2. **校准器接入**：浅思维验证行走灵枢 auto_verify（已有端点）
3. **教训边界**：lesson 节点邻域检测（已有 tags 机制）
4. **种子化**：翻译表规范词/识别卡 → 种子节点（agent 建边后自然融入）
5. **深挖工具**：engram_condition（补）+ 已有 open/recall/verify/respond
