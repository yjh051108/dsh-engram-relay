# 统一路由：记忆与世界知识的同一套算法（Zero-Embedding Unified Routing）

> 设计目标：一次查询，同一套路由算法，同时召回「我的记忆」（engram）与「世界知识」（灵枢），全程零 embedding 模型——纯词项/统计/图算法，可解释、可审计、可收敛。

## 核心洞察：两套系统其实共享一个语义骨架

| 资产 | 灵枢（世界知识） | engram（记忆） | 本质 |
|---|---|---|---|
| 语义入口 | 翻译表（俗语→规范词）≈ 领域 WordNet | 无（靠词面+共现） | 词网 |
| 相似度 | 二元组 Jaccard + 学科路由 | n-gram Jaccard × 词频 | 词项匹配 |
| 语义桥 | 手写翻译表（人工枚举） | 共现桥（PMI 自动学） | 查询扩展 |
| 图 | BASE_RELATIONS（学科间边） | 因果/链接图 | 图传播 |
| 索引 | 全库扫描（≤500） | 哈希倒排 O(1) | 索引 |

**融合点：让灵枢的「规范词空间」成为跨层枢纽——记忆和知识都进同一个规范词索引。**

## 统一路由管线（一次查询，双层召回）

```
查询「铁门放外面久了为什么生锈？」

① 翻译表编码（灵枢资产）→ {氧化, 生锈, 铁} 规范词集（带权重）
② 共现桥扩展（engram 资产）→ +{腐蚀, 铁锈, 化学变化} 语义邻居
   （PRF 式：查询词+规范词的库内共现邻居，跨层同一张共现表）
③ 统一倒排检索（规范词 → 知识卡 ∪ 记忆节点）一次寻址
   记忆写入时也过翻译表打标（进同一规范词索引）
④ 统一评分（同一公式，两层共用）：
   score = α·lexical(Jaccard×词频) + β·cooc(共现桥) + γ·graph(统一图传播)
   统一图 = 因果边 ∪ BASE_RELATIONS（记忆↔知识也能连边）
⑤ 知识层校验（灵枢 D_norm 诚实边界）→ 标注 ✓锚定/?图谱外

输出：记忆入口 + 知识卡（同一次路由，同一排序体系）
```

## 与文献的对应（零 embedding 的学术支撑）

| 我们的机制 | 文献 | 关系 |
|---|---|---|
| 翻译表（俗语→规范词） | WordNet query expansion（N-layer vector space） | 领域定制词网替代通用词网——灵枢已有，升级为跨层枢纽 |
| 共现桥（词-词共现扩展） | Pseudo-Relevance Feedback（kernel co-occurrence enhancement） | 经典 PRF 的库内实现——engram 已在做，扩展为跨层共现表 |
| 规范词权重×IDF | SPLADE（sparse lexical representations） | SPLADE 用 ML 学词项权重；翻译表+IDF 是它的无监督可解释版（零训练） |
| 统一倒排 | BM25 族 | 规范词倒排 + IDF 权重，工程成熟 |

## 渐进落地（四步，每步可独立验证）

- **P1 记忆规范词打标**：engram_store/蒸馏写入时过翻译表，记忆带规范词标签（进统一索引的前提）——零风险，写时多一步
- **P2 统一倒排**：规范词 → {知识卡, 记忆} 一个索引，一次检索双层召回——替换灵枢全库扫描（O(N)→O(1)）
- **P3 跨层共现表**：知识卡∪记忆共现一张表——「我的经验」与「世界知识」的语义桥自动互连
- **P4 统一图**：因果边∪BASE_RELATIONS 合并传播——记忆↔知识的跨层关联可被图通道发现

## 收益

1. **一套算法两层内容**：路由代码唯一（lexical/cooc/graph 融合），记忆和知识只是统一索引的两个命名空间
2. **可解释**：每次命中可拆通道（词面/桥/图），审计友好
3. **零模型**：SPLADE 是「要训练的词项权重」，我们用翻译表+IDF+共现统计——等价且白箱
4. **跨层语义自动互学**：共现桥跨层建——灵枢翻译表覆盖不了的俗语，记忆语料里自动学桥

## 风险与边界（照实）

- 翻译表仍是冷启动关键（规范词空间的质量 = 两层的共同地基）——P1 后记忆的规范词由表覆盖，未覆盖俗语靠共现桥渐进补
- 共现桥需要语料量（冷启动稀疏）——灵枢 26 卡+记忆 479 条起步，随使用收敛（PRF 同性质）
- 规范词空间会漂移（新俗语）——可定期用共现桥 top 词增量补充翻译表（半自动词网维护）
