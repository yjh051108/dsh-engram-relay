# 风识 v2 · MAXential×风识 融合设计（推理融合）

> 目标：让推理链（分支树）成为记忆图的一部分——分支是图的临时展开，合并是图收敛，
> 分支结论沉淀为记忆（分支记忆化），推理压力时自动召回（压力阀 recall），合并前白箱校准。

## 一、现状（v0.3.x 已就绪的基础）

- 记忆图：agent 自组织建边/强化/遗忘（engram）——分支可映射为临时子图
- 灵枢校准：D_norm 白箱验证——合并前校准的直接工具
- 跨端联动：图谱无命中→记忆线索（知+忆双通道）
- 学习闭环：补卡/补簇/仪表盘/收敛数学

## 二、v2 三个融合机制

### 1. 分支记忆化（branch → memory）

```
分支探索 = 图上的临时展开（假设节点 + 候选边）
close_branch 时：
  ① 分支结论 → engram_store（kind=decision，causes=主链结论）
  ② 分支的关键中间态 → engram_store（kind=note，links=结论节点）
  ③ 分支与主链的分歧点 → 记忆的 causes/effects 边（图谱保留决策树）
效果：合并后分支思考不丢失——成为图谱中的决策分支（可回溯/可复用）
```

### 2. 压力阀 recall（deep reasoning 自动召回）

```
信号：同一主张二次验证 / 多步推理卡住 / 分支数 > 3
动作：自动 engram_recall（压力主题）→ 图谱相关决策注入推理
数学：压力阈值 = 分支深度 × 0.3 + 未决分支数 × 0.2（经验标定）
与浅思维的关系：浅思维 = 每轮低预算注入；压力阀 = 深推时高预算召回（分层）
```

### 3. 合并前校准（merge 前白箱验证）

```
merge_branch 前：分支结论 → engram_verify（灵枢 D_norm 锚定）
  已锚定 → 正常合并 + 结论入记忆（带锚定证据）
  图谱外 → 不裁决——分支结论标记 pending（诚实：不强行并入主链）
  反锚定 → 分支结论标注冲突（保留在分支，不污染主链）
效果：合并 = 校准过的图收敛（不是盲目并入）
```

## 三、落地路径

| 阶段 | 内容 | 依赖 |
|---|---|---|
| v2.1 | 分支记忆化引导（HEADER + 工具描述 + close_branch 前后检查） | 无（引导层） |
| v2.2 | 压力阀 recall（relay 钩子：深推信号 → 自动 recall 注入） | 会话状态接口 |
| v2.3 | 合并前校准（merge 钩子 → verify → 结论入记忆） | DSH merge 事件 |

## 四、哲学对齐

- 算法是参谋 agent 是主人：压力阀/校准只提供信号，决策权在 agent
- 诚实边界：图谱外不裁决——合并前校准不强行锚定
- 自组织：分支记忆化后，决策树自组织成图谱结构（非硬编码）
- 零 embedding：v2 保持纯算法主路径（词桥/共现/图——不引入向量）
