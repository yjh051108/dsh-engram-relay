# engram 唤醒系统数学建模报告

> 按数学建模竞赛规格：问题重述 → 假设 → 符号 → 模型 → 数据校准 → 求解 → 灵敏度 → 结论。

## 摘要

engram 唤醒系统在每轮对话前，从记忆图谱中检索与当前查询相关的记忆并注入提示词。核心矛盾：**注入太少漏掉关键记忆（性能损失），注入太多浪费上下文且可能误导（成本）**。本报告建立召回-成本双目标模型，用真实 bge 语义分布校准，给出阈值/预算/召回数的最优参数组合与灵敏度结论。

## 1. 问题重述

给定 N 条记忆、每轮一个查询 q，系统以概率 p 为"相关查询"（q 与某条记忆语义相关）。唤醒决策为：注入记忆集合 S ⊆ 记忆。目标：

- **最大化召回率 R**（相关查询注入了正确记忆的比例）
- **最小化成本 C**（注入 token 总量，含误注入）

## 2. 模型假设

- H1：查询-记忆的语义相似度 s ∈ [0,1]（bge 余弦），相关对 s ~ D_rel，无关对 s ~ D_irr，两分布**由真实数据校准**（§4）；
- H2：哈希粗筛是无损的（共享词的记忆必进候选，词汇无关的必不进）——候选集即"有词汇重叠"的记忆；
- H3：注入预算 B 内，每条记忆的入口渲染成本固定 c0（标题+摘要+因果注 ≈ 120 token）；
- H4：无关查询经哈希粗筛后仍有候选的概率为 h（词汇巧合），此时误召取决于阈值。

## 3. 符号说明

| 符号 | 含义 |
|---|---|
| θ | 语义阈值（决策变量） |
| B | 注入 token 预算（决策变量） |
| K | 最大召回条数 maxWakePerTurn（决策变量） |
| R(θ) | 召回率 = P(s_rel ≥ θ) |
| E(θ) | 误召率 = P(s_irr ≥ θ) |
| C(θ,B,K) | 每轮期望注入 token |
| F(θ,B,K) | 综合效用（召回收益 − 成本） |

## 4. 数据校准（真实 bge-small-zh，86 条记忆 × 8 查询）

| 分布 | n | mean | std | min | p25 | p50 | p75 | max |
|---|---|---|---|---|---|---|---|---|
| 相关 D_rel | 33 | 0.516 | 0.088 | 0.322 | 0.448 | 0.539 | 0.576 | 0.723 |
| 无关 D_irr | 312 | 0.293 | 0.099 | 0.101 | 0.218 | 0.277 | 0.366 | **0.752** |

**关键事实**：两分布**重叠显著**（无关 max 0.75 > 相关 mean 0.52）——阈值无法完美分离，必须在召回与误召间权衡。

## 5. 模型建立

### 5.1 召回模型

R(θ) = P(s ~ D_rel ≥ θ)，由真实分布经验估计（§4 表）。

### 5.2 成本模型

C(θ, B, K) = p · min(K, ⌊(B−c_head)/c0⌋) · c0 + (1−p) · h · E(θ) · min(K, ⌊(B−c_head)/c0⌋) · c0

其中 c_head ≈ 40 token（注入头声明），c0 ≈ 120 token/条。

### 5.3 缓存影响模型

长会话（L token 上下文）下，注入位于消息尾，缓存命中率：

H = 1 − (每轮新增 token) / L = 1 − (u + C) / L

其中 u = 用户消息+工具结果（~1300 token/轮）。注入对命中的损耗与 L 成反比。

## 6. 求解

### 6.1 阈值（ROC 权衡，Youden 指数 J = R − E）

| θ | R | E | J = R−E |
|---|---|---|---|
| 0.35 | 97% | 27.6% | 69.4 |
| 0.40 | 88% | 17.9% | **70.1** |
| 0.42 | 82% | 14.4% | 67.6 |
| 0.45 | 73% | 8.7% | 64.3 |
| 0.50 | 58% | 1.0% | 57.0 |

**Youden 最优 θ* ≈ 0.40**。考虑漏召损失 > 误召损失（答不出 vs 多几百 token），θ 取 0.40~0.42；当前 0.42 兼顾（误召降至 14.4%，召回损失可接受）。

### 6.2 预算与条数

- K=2~3 与 B=200 时单轮成本 = 40 + 2~3×120 ≈ 280~400 token；
- B=100 时 K=1（40+120=160）——召回上限受限；
- **推荐 (θ, B, K) = (0.42, 200, 3)**：单轮 ≤ 400 token，1M 上下文占比 < 0.05%。

## 7. 灵敏度分析

| 参数 | 扰动 | 影响 |
|---|---|---|
| θ +0.03 | 误召 −6% / 召回 −9% | 最敏感（主导权衡） |
| B −100 | 成本 −120 tok / 召回条数 −1 | 次敏感 |
| K −1 | 因果邻居丢失（传播失效风险） | 影响因果召回 |
| N（记忆数）↑ | 无关误召↑（哈希碰撞） | 需随 N 提高 θ 或依赖哈希防线 |

## 7b. 多重比较问题与自适应阈值

**发现**（校准仿真）：固定阈值下，误召随候选数 n 增长而必然发生——单条无关过阈概率 q≈10%，n 条候选"至少一条误过"概率 ≈ 1−(1−q)^n，n=100 时 ≈100%。

**修正**：自适应阈值 θ_eff = θ + 0.03·log2(n/16)（候选翻倍 +0.03 的温和 Bonferroni 近似）。注意：真实系统哈希粗筛已把无关候选压到个位数（词汇不重叠即空），多重比较主要影响候选膨胀场景（通用词碰撞）。

## 7c. 仿真局限（诚实声明）

- 仿真的无关查询候选数被高估（仿真记忆含大量共享通用词，真实记忆词汇更分散）——真实系统误召低于仿真值；
- 哈希粗筛是"第一道防线"，其有效性依赖词汇分布，仿真未完整建模；
- 结论用于**参数方向与量级**，最终以真实环境实测为准（生产已实测：无关→空、相关→3 条）。

## 8. 结论

1. **阈值是唯一主导旋钮**（θ* ∈ [0.40, 0.42]，Youden + 不对称成本修正）；
2. **当前生产参数 (0.42, 200, 3) 已接近最优**；
3. 无关误召的**第一道防线是哈希粗筛**（词汇无关即空，bge 阈值只是第二道）；
4. 后续改进方向：**时序衰减**（近期记忆加权）、**随 N 自适应 θ**（数量增长时提高阈值）。
