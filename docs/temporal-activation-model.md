# 记忆时序激活的数学建模（ACT-R 风格，类脑记忆系统）

> 数模规格：问题 → 假设 → 符号 → 模型 → 参数 → 与系统映射 → 六场景验证。

## 摘要

用户直觉"时序才是正确的"指向人脑记忆的数学本质：记忆不是静态条目，是**随使用与时间连续演化的激活状态**。本文以 ACT-R（认知架构）的激活方程建模：每条记忆的激活值由**强化历史**（写入/命中/展开/链接）与**时间衰减**共同决定，检索 = 激活阈值的 sigmoid 判定。模型统一解释六类场景（问题重现/版本幻觉/事件洪水等），替代当前"相似度 + 排序权重"的工程式拼接。

## 1. 问题重述

记忆系统在 1 亿 token、三跨（跨会话/跨记忆/跨时间）规模下，检索需要回答：**这条记忆"现在"有多值得被想起？** 当前实现用"语义余弦 × 时序加权（1+0.25·e^(-Δturn/20)）"近似——但时序不是乘法修正项，是记忆状态的**核心维度**。

## 2. 模型假设

- H1：每条记忆的"可想起度"是一个标量**激活值 A**（类脑：海马-皮层网络的激活强度）；
- H2：激活由**强化事件**维持：写入、被检索命中、被展开、被链接都是强化——每次强化记一个时间戳，激活 = f(全部强化时间与现在的时间距离)；
- H3：**遗忘是时间的自然结果**（无强化的记忆激活按幂律衰减——Ebbinghaus 曲线的幂律形式）；
- H4：**干扰加速遗忘**：同主题新版本写入时，旧版本被干扰（激活衰减加速/当前性归零）——版本链的数学；
- H5：检索是**带噪声的阈值判定**：P(被注入) = sigmoid(激活 - 阈值)。

## 3. 符号

| 符号 | 含义 |
|---|---|
| A_i | 记忆 i 的激活值 |
| B_i | 基础激活（强化历史的时间积分） |
| t_k | 距第 k 次强化事件的经过时间（turns 或 wall-clock） |
| d | 衰减系数（ACT-R 典型 0.5） |
| W_ij, S_ji | 关联权重与扩散激活（语义/因果边贡献） |
| τ | 注入阈值（sigmoid 中点） |
| s | sigmoid 温度（判定锐度） |
| ε | 噪声（对数正态） |

## 4. 模型建立（核心方程）

### 4.1 基础激活（ACT-R 激活方程）

```
B_i = ln( Σ_{k ∈ 强化事件(i)} t_k^(-d) )
```

- **每次强化**（写入/命中/展开/链接）往求和里加一项 t^(-d)；
- 刚强化的（t 小）贡献大；久未强化的（t 大）贡献衰减——**使用即巩固、闲置即遗忘**（类脑）。

### 4.2 总激活（关联扩散）

```
A_i = B_i + Σ_j W_ij · S_ji + ε
```

- 关联项：语义相似（bge 余弦）与因果边贡献的扩散激活（当前检索分数进入此项）；
- 噪声 ε：检索的随机性（同一查询不同时刻可能想起不同记忆——人脑亦如此）。

### 4.3 检索概率（阈值 sigmoid）

```
P(注入 i) = 1 / (1 + e^(-(A_i - τ) / s))
```

- 激活超过阈值才"想起来"；s 小 → 判定锐利，s 大 → 模糊宽容。

### 4.4 干扰与废止（版本链）

```
新版本 v2 写入时：A(v1 同主题) *= ρ  （ρ ≈ 0.1，当前性归零）
```

- 同主题修订 = 旧版本激活被干扰压到阈值以下 → 不再注入（沉入历史）；
- 检索"当前状态" = argmax A（同主题内）。

### 4.5 价值分流（事件洪水治理）

```
强化类型权重：写入(1) < 命中(2) < 展开(3) < 链接(4)
且事件类记忆（一次性）无后续强化 → B 自然衰减到阈值下 → 自动沉眠
```

- **不需要显式删除**——无强化的事件记忆按遗忘曲线自动退出入口层（类脑：不复习就忘）；
- 知识类记忆因反复命中/展开而持续巩固（类脑：重要的记一辈子）。

## 5. 参数初值（待仿真标定）

| 参数 | 初值 | 依据 |
|---|---|---|
| d（衰减） | 0.5 | ACT-R 典型值 |
| τ（阈值） | 0.0（对数域） | 对应当前语义阈值 0.42 的校准锚点 |
| s（温度） | 0.4 | 温和锐利 |
| ρ（废止干扰） | 0.1 | 旧版本当前性归零 |
| 强化权重 | 写1/命中2/展开3/链4 | 使用深度递增 |

## 6. 与现有系统的映射（迁移路径）

| 现有 | 迁移到 |
|---|---|
| 时序衰减 1+0.25·e^(-Δturn/20) | **基础激活 B_i**（强化历史的完整积分） |
| bge 余弦（检索分数） | **关联扩散项** ΣW·S |
| 语义阈值 0.42/0.5 硬过滤 | **sigmoid 概率阈值**（软判定，带噪声） |
| 簇内"最新代表" | **argmax A**（最高激活 = 最新且最常用） |
| 手动删除/降级 | **遗忘自然发生**（无强化衰减）+ 干扰废止 |

## 7. 六场景验证（模型如何闭环）

| 场景 | 模型行为 |
|---|---|
| ① 问题重现 | 旧诊断记忆被"命中/展开"强化过 → B 高 → 与新记忆**同时过阈值**（双路注入） |
| ② 版本幻觉 | v2 写入时 v1 激活 ×ρ → 只有 v2 过阈值（版本废止） |
| ③ 语境错配 | 关联扩散项与语境的 W 权重（会话主题层）——分层下探的数学位置 |
| ④ 事件洪水 | 事件记忆无强化 → B 按 t^(-0.5) 衰减 → 数周后自动低于阈值（沉眠） |
| ⑤ 事实过期 | 新事实写入触发旧数字记忆的干扰（ρ）→ 旧数字退出当前 |
| ⑥ 状态恢复 | 工作快照 = 会话收尾时的一次"高权重强化"（写 4 级权重）→ 长期保持高激活 |

## 8. 类脑论证

- 幂律遗忘（t^(-d)）：Ebbinghaus 遗忘曲线的数学形式；
- 强化即巩固：间隔重复（spacing effect）的自然涌现；
- 干扰致忘：记忆竞争（interference theory）的版本废止；
- 检索概率化：人脑"有时想得起有时想不起"的噪声本质；
- **结论：时序不是检索的一个特征，是记忆状态的时间导数——记忆系统因此从"数据库"变成"会忘记的脑"。**

## 9. 实施顺序

1. 强化事件记录（写入/命中/展开/链接 → 时间戳数组，存储于节点）；
2. B_i 计算接入 wake 排序（替代现有时序加权）；
3. sigmoid 阈值替换硬阈值（先与现有 0.42 校准对齐）；
4. 同主题修订触发干扰废止（与写入管线一起）；
5. 仿真标定参数（六场景 + 真实数据）。
