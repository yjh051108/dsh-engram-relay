# 风识调优方法论（实战驱动 · 数学实证）

> v0.3.0→v0.3.18 的 24 轮调优沉淀：方法、数学工具、案例、反模式。

## 一、核心方法：subagent 实战驱动闭环

```
① 派 subagent 以真实用户身份使用（全新会话、工具全量）
② 报告可复现的问题（具体到返回内容）
③ 修复 + 自测验证（HTTP 路径，不是直调）
④ 再派 subagent 复验（回归 + 新问题）
⑤ 同步发布包 + 推送 + 隔离验证
```

**关键**：subagent 的 HTTP 实测能发现直调发现不了的 bug——
最典型案例：补簇 `self.` 缺失（直调 `h._auto_cluster` 正常，HTTP 路径 NameError 被 except 吞）

## 二、数学工具（每个都产出过实质改进）

### 1. 阈值实证（D_norm 0.68→0.65）
```
45 正例（卡名）+ 15 负例（无关句）→ D_norm 分布 → 阈值扫描最大化 F1
结果：正例 med 0.514 / 负例 med 0.719 → 最优 0.65（F1 0.95，假阳性 0）
```
教训：先测分布再定阈值——0.68 的 13% 假阳性来自重叠区

### 2. 权重网格扫描（VERIFY_WEIGHTS）
```
四维 U 矩阵预计算 → 网格扫描 1771 组合（步长 0.05）
结果：(0.30,0.25,0.30,0.15)→(0.40,0,0.10,0.50)，F1 0.740→0.918
发现：统一锚定后 behavior 维度冗余；prediction_error（claim 重叠）是关键
```

### 3. 收敛性仿真（学习系统不失控）
```
未覆盖主题池稀释-学习模型：C/(C+U) 覆盖率 → 稳态 c* = λ/(λ+n)
结论：单调收敛、卡库增速 ≤ L/日（上限是覆盖率旋钮）
```

### 4. 匹配粒度升级（字符→2-gram）
```
字符级 Jaccard 对长文档惩罚 + 中英混合失效（1+1 vs 1加1）
升级 bigram_hit（查询侧 2-gram 命中率）→ U_behavior/U_prediction 修正
```

### 5. 域分加权（同域错配）
```
域分 × (0.2 + 0.8·bigram_hit(查询, trigger+卡名))
同域多卡时 trigger 词面相关的卡拿满域分——两级检索（域粗筛→trigger 精排）
```

## 三、反模式（踩过的坑）

| 反模式 | 教训 | 对策 |
|---|---|---|
| except 吞异常 | NameError 静默 3 轮 | 异常落盘日志 |
| 直调 ≠ HTTP 路径 | self. 差异 | 验收必须 HTTP |
| 膨胀 trigger | 2-gram 全并入 → 噪声 | 手写∪术语，IDF 过滤 |
| 整句卡名 | LLM 把查询当 name | 质量门（长度/疑问词） |
| 同日上限误认 bug | 保护生效无日志 | 上限日志进 debugLog |
| 发布包种子不同步 | 主库改、md 未改 | 隔离验证逐值对比 |

## 四、验证铁律

1. **HTTP 路径验证**（不是函数直调）
2. **回归集**（核心查询逐值对比：记住/搜索/信息差/铁门/开发域）
3. **隔离验证**（发布包全新播种 vs 主库逐值一致）
4. **负例测试**（无关查询不误命中）
5. **数学证据**（阈值/权重/收敛——每个阈值都有实证）
