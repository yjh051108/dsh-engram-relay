# 风识学习系统收敛性（数学建模）

> 验证：自动补卡/补簇的学习系统不会失控——覆盖率收敛、卡库增速受控。

## 模型（未覆盖主题池稀释-学习）

```
状态：C = 已覆盖主题（有卡），U = 未覆盖主题（新主题累积池）
每轮：
  新主题 n ~ Poisson(novel/D) → U += n
  查询命中率 c = C/(C+U)
  学习（求助率 θ=0.3）：miss 触发补卡（上限 L/日），覆盖 U 的主题
补簇：弱命中桥接（对覆盖率二阶，计入学习速率增益）
```

## 仿真结果（K=200 已知主题，D=200 轮/日，T=20000 轮）

| 配置 | 稳态覆盖率 c* | 收敛性 |
|---|---|---|
| L=5, novel=2/日 | 0.958 | 单调收敛 ✓ |
| L=5, novel=10/日 | 0.558 | 单调收敛 ✓ |
| L=5, novel=50/日 | 0.136 | 单调收敛 ✓ |
| L=20, novel=50/日 | 0.420 | 单调收敛 ✓ |
| L=20, novel=200/日 | 0.109 | 单调收敛 ✓ |

## 数学结论

1. **单调收敛**：覆盖率 c(t) 无振荡地收敛到稳态 c*——学习速率 λ 与主题到达率 n 的平衡
2. **稳态公式**：c* = λ/(λ+n)——λ 由上限与求助率决定（λ ≈ min(L/日, θ·miss)）
3. **卡库受控**：dC/dt ≤ min(L, θ·miss)——线性增长，斜率 ≤ L/日（上限防爆炸）
4. **不失控保证**：上限 L = 覆盖率旋钮（L↑→c*↑）；质量门 = 噪声过滤器（再减无效增长）

## 设计映射

| 模型参数 | 风识实现 |
|---|---|
| L（补卡上限） | gapDailyLimit（默认 5/日，可配置） |
| 质量门 | 补簇 algo_score≥0.05 + 词提取过滤 |
| 求助率 θ | agent 主动 verify/respond（意图驱动） |
| 补簇 | 弱命中≥3 次自动建词桥（零 LLM） |

## 结论

学习系统在数学上可证明收敛与受控：不会覆盖爆炸（≤L/日）、不会振荡（单调）、
覆盖率可预期（c* = λ/(λ+n)）。「自动成族/自动学习」的收敛性有据可依。
